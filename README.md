# OpenBuy 展会智能镜 · 2026-10-13

独立的 V1.1 镜端、工作人员后台和 Node API，包含 99 个展会预设素材及本地挥手识别模型。前端与 API 由同一入口提供。

## 启动

当前项目目录为 `/home/a/文档/ChatGPT/展会`。Ubuntu 桌面已放置 **启动展会局域网** 快捷方式，双击即可启动后台并打开浏览器；本目录保留同名 `.desktop` 启动文件。若首次提示，选择“允许运行”。也可运行 `bash 启动局域网预览.sh`。关闭启动窗口后服务继续运行，重复启动不会创建第二份服务；重启电脑后登录当前用户会自动恢复。

当前 Ubuntu 工作站使用 [http://xuxin.local:10101/](http://xuxin.local:10101/) 作为工作人员后台，镜端使用 `https://xuxin.local:10202/`。本机 `miror-preview.service` 已保存 `MIROR_LAN_HOSTNAME=xuxin.local` 和 `MIROR_EXHIBITION_PORT=10101`，登录后自动运行。Linux 需运行 Avahi 并安装 `avahi-publish-address`；网关会广播当前局域网 IP，网络地址变化时自动更新。初始化证书与启动时应传入同一组环境变量。其他部署未配置这些变量时，沿用下文的原默认地址。

安装 Node.js 22.13 或更新版本（建议 24），本地交付 ZIP 已包含 dist；从 GitHub 获取源码时，先执行 npm ci 和 npm run build。解压整个目录后执行：

```sh
npm ci --omit=dev
npm run setup
npm start
```

`setup` 只在缺少时创建环境文件与素材库，并生成本机 HTTPS 证书；重复执行保留已有配置与素材。`npm start` 同时启动前端、API、HTTP 和 HTTPS。窗口需保持运行，按 Ctrl+C 停止。

- 工作人员后台：[http://xuminghong.local:10601/](http://xuminghong.local:10601/)
- 本地入口：[http://xuminghong.local:10200/](http://xuminghong.local:10200/)
- 镜端：[http://xuminghong.local:10200/v1.1/exhibition/screen](http://xuminghong.local:10200/v1.1/exhibition/screen)，自动进入 HTTPS 10202 摄像头页面。

macOS 可双击 `启动展会局域网.command`。脚本会自动查找已安装的 Node（包括 Codex 本机运行时），需要安装带 npm 的 Node.js。首次自动安装依赖、初始化并启用后台托管，关闭窗口、锁屏或熄屏后继续运行；重启后登录自动恢复。后台运行文件与持久数据保存在 `~/Library/Application Support/Miror/preview/<目录标识>/`，不依赖后台进程读取“桌面”或“文稿”。双击 `停止局域网预览.command` 停止本包服务并解除防眠。主动睡眠、合盖、退出登录、关机或断网会影响访问。

Windows 可双击 `启动展会.cmd`。首次安装需联网；其他电脑需要能解析 `xuminghong.local`，或使用后台输出的局域网 IP 备用地址。设备与服务电脑应在同一局域网，防火墙需允许 HTTP 10200/10201/10601 和 HTTPS 10202。

## 摄像头与 XMAX

首次在镜端设备上安装并信任本包生成的 `.data/lan-tls/root-ca.crt`，也可从后台下载公开 CA。初始化不会修改系统信任。

在后台当前设备设置区的 HTTPS 表单中配置每台镜的 XMAX SK 和区域。HTTP 页面只接收保存结果，不接收密钥。也可在服务端 `.env` 配置默认 `XMAX_API_KEY`。密钥、会话记录和证书私钥仅保存在运行电脑。前台运行数据在包内 `.data`；macOS 后台托管的数据在上述运行目录的 `data/`，环境文件为 `app/.env`。搬迁已有运行数据时需同时保留数据目录中的加密密钥，不能只搬数据库。

素材库首次以演示模式初始化。配置 SK 后在后台选择实时模式；镜端仅准备本地取景，点击“开始体验”才启动生成。临时凭证有单次限制和有效期；不设置本地累计预算，额度不足以 XMAX 返回为准。

展会连续体验不按 96 秒或结果完成消息自动暂停。连续模式下，可恢复的连接故障按 1–30 秒退避重连，临时凭证按原有安全流程续接；旧会话确认停止后才开启下一段。主动暂停会取消自动恢复，大屏回到本地取景和“开始体验”，再次点击才启动。实际额度不足、摄像头断开或凭证停止未确认仍需处理。浏览器测试在持续使用时滚动续期，关闭或失联后清理。

## 同机多摄像头、安卓或网页显示

Android 0.6.16 起可在原生镜端长按 Logo，将视频来源选为「局域网电脑」。电脑在后台选中该智能镜，打开「安卓联动」，选择连接到电脑的摄像头；大屏绑定保持不变。电脑源入口为同主机 HTTPS 10202 下的 `/v1.1/exhibition/computer?mirror=<镜编号>`，Ubuntu 仍使用 `xuxin.local`。

同一台电脑可为多台智能镜各用一个摄像头，同时运行。后台每台智能镜都有「安卓联动」和「HDMI 大屏」入口，可组合为两个安卓、两个网页或安卓加网页。网页大屏直接使用该智能镜的素材和控制状态，无需安卓在线，也不改变已有绑定；普通「网页大屏」链接保留在「设备入口」，地址增加 `&output=browser`。每台智能镜同一时间只开一个视频源，切换输出前先停止体验并关闭旧页面。

「HDMI 大屏」打开独立 HTTPS 窗口，地址增加 `&output=browser&presentation=hdmi`。在电脑 Chrome 中授权显示器访问，再点击目标屏全屏显示完整试衣界面；macOS 需使用扩展显示，智能镜切到 HDMI 输入。后台留在电脑屏幕，摄像头、选款、手势和生成均由电脑运行。重复点击同一设备的入口只聚焦已有窗口；选屏不刷新页面。无法自动选屏时，可手动移动窗口并全屏。打开页面只准备摄像头，点击「开始体验」才生成；已选择的屏幕断开后停止生成，重连后需重新投屏并开始。未授予显示器权限时，手动全屏无法可靠检测拔插，断开前需先停止体验。

首次使用时，在支持 Web Locks 的同一浏览器中自动选择空闲摄像头；已经保存的摄像头被另一路使用时提示改选。同名摄像头带编号，选择仍按真实设备 ID 保存。插拔设备会更新列表，关闭一路只释放该路摄像头。不同浏览器或其它采集软件不共享此占用协调。

电脑源的「电脑摄像头 → 摄像头方向」支持默认、顺时针 90°、180°、逆时针 90°。「摄像头画质」可选 1080p 或 4K（Android 0.6.17 起）。摄像头、画质与方向按当前浏览器、当前智能镜分别保存，刷新后恢复；停止体验后可修改。「发送到大屏」显示当前摄像头或生成画面的实际发送分辨率和帧率。旋转后的画面用于预览、手势与 XMAX 输入；竖向 4K 预览以原始横向视频传输，在安卓显示时旋转，避免竖向 4K 解码限制。生成结果不再旋转，分辨率取决于云端输出；4K 档不会将低分辨率视频放大成 4K，也不覆盖 XMAX SDK 的默认上行编码规格。镜像开关只控制预览显示。

浏览器测试和浏览器镜端也可点击底部摄像头图标，在「摄像头方向」中预览并保存旋转；取消会恢复原摄像头与方向。测试页的设置只保存到当前测试，不影响正式镜端或其他测试。安卓 App 继续通过「安卓联动」接收电脑画面；浏览器测试链接不是移动端投屏链接。

电脑负责摄像头采集、手势识别和 XMAX 会话，并通过局域网 WebRTC 将当前预览或生成视频传给安卓。安卓只解码显示和提交触摸操作，不启动摄像头、本机识别器或 XMAX 会话；解码与屏幕渲染仍会消耗设备资源。仅传视频，不采集声音。电脑与大屏须能在局域网直接互通；未配置公网中继。

进入电脑源页面只准备预览，点击「开始体验」后才生成。一个智能镜同一时间仅允许一台电脑源；关闭电脑源会停止其连接，短暂断线会重连。超过连接保留时间会停止体验，重新连接后需再次开始。电脑浏览器须持续运行且不进入睡眠。安装与兼容模式见 [Android 说明](android/exhibition/README.md)。

## 技术接手

后台“换装服务”切换区域暂时隐藏，XMAX SK 配置继续显示，已有服务配置与密钥保留。恢复显示时，在构建环境设置 `VITE_EXHIBITION_SHOW_PROVIDER_SETTINGS=true` 后重新构建（例如 `VITE_EXHIBITION_SHOW_PROVIDER_SETTINGS=true npm run build`）。此开关同时作用于 HTTP 后台内嵌表单和 HTTPS 配置页。

- `src/`：独立智能镜和后台界面。
- `server/`：多镜、素材、设备、凭证和实时会话 API。
- `shared/`：前后端共享类型与命令协议。
- `dist/`：可直接运行的前端构建；改源码后需重新构建。
- `seed/`：99 个预设素材及 SHA256 清单，不包含设备绑定和历史会话。
- `scripts/`：初始化、静态服务、HTTP/HTTPS 网关和 macOS 后台托管。
- [docs/API.md](docs/API.md)：接口、请求示例与完整实时会话流程。

外部接口前缀是 `/v1.1/api/exhibition`；前端使用同源相对地址，网关将其代理到内部 API 的 `/api/exhibition`。**不要只上传 `dist` 到普通静态空间**；后台 API 与 HTTPS 网关也必须一起运行。`dist/index.html` 需要由服务打开，不支持双击文件预览。

内部 API 3002 与静态服务 5173 仅监听本机；前台启动和 macOS 托管均使用同一组固定端口。端口被其他工程占用时会明确报错，不停止占用程序。本机正在运行原工程时，独立包不能同时占用同一组入口。

启动环境检查（不安装依赖、不启动服务）：

```sh
bash scripts/launch-mac.sh doctor
```

修改后验证：

```sh
npm ci
npm run build
npm test
npm run test:runtime
npm run test:package
```

普通界面开发可用 `npm run dev`；完整局域网与摄像头流程使用 `npm start` 或 macOS `npm run lan:start`。停止后台服务后重新启动会同步源码与依赖，已有后台数据与环境配置保留。运行数据与本机依赖不进入交付压缩包，应在目标系统重新安装依赖。本包不包含主站、V1.0、生产密钥或现场运行记录，未配置自动发布。

## 镜端素材栏

后台“控制与设置 → 设备设置 → 素材栏列数”可选择一列或两列，选择后自动保存，每台镜子独立生效；默认两列。一列时同步收窄镜端素材侧栏。结束体验并等待实时会话停止后可修改。

## 翻页笔换装

Linux 工作站连接以键盘方式输入的 USB／蓝牙翻页笔后，将镜端浏览器页面保持在前台并聚焦。`PageUp`／左箭头／上箭头切上一款，`PageDown`／右箭头／下箭头切下一款；按后台当前模式的启用顺序首尾循环。待机时只选款，点击“开始体验”后按键才切换实时素材；按键不会开始或结束体验。

长按只执行一次，当前切换确认后可再次按键；暂停、停止、断连或续接时阻止切换。后台预览与输入框不响应这些快捷键。无需安装 `evdev` 或启动 Python 监听程序；实际翻页笔须向浏览器发送上述键码，设备到场后再做实机联调。

## 手掌识别与后台参数

后台“控制与设置 → 设备设置 → 手势识别”可多选手掌识别、左右挥手，默认仅启用手掌。五指自然并拢也可识别，默认确认时间 300 ms；持续举掌只切换一次。全部取消勾选即可关闭。每台镜子独立保存，修改后点击“保存识别设置”，恢复默认也需保存。

“识别参数”提供 MediaPipe 手检测/存在置信度、框跟踪阈值、手掌确认时间、收手间隔、帧率上限和输入分辨率。网页采用浏览器摄像头与 Canvas 取帧，没有 OpenCV 运行时。完整范围和请求格式见 [API 文档](docs/API.md)。后台仅在体验结束、实时会话停止后允许保存。

镜端 URL 加 `diagnostics=1` 打开诊断，支持导出和清空。记录仅在页面内存中保留最多 10,000 条，不包含密钥、图像和原始关键点。“已看到新衣服”是人工观察值，SDK 提交成功和会话首帧不能替代逐套服装确认。现场识别准确率、重复率及生成画面仍需真人验收。

本轮源码与测试结果见 [手势设置验收](docs/verification-gesture-settings-20261013.json)。可选 Mac 浏览器回归脚本为 `scripts/check-exhibition-gestures.mjs` 和 `scripts/check-exhibition-gesture-settings.mjs`，需先安装 `@playwright/test` 并有 Google Chrome；构建后使用 `GESTURE_CHECK_DIST="$PWD/dist" node scripts/check-exhibition-gesture-settings.mjs`。脚本使用假摄像头和隔离 API，不启动真实 XMAX。

### 完整网页无线投屏

V1.1 后台右上角「无线投屏」打开同主机 HTTPS 10202 的独立试衣标签页。Mac 使用新版 Chrome，安卓使用支持整页接收的 0.6.21 或更新 APK；安卓视频来源选「局域网电脑」，双方在可互通的局域网内。点击「共享试衣界面」，在 Chrome 中选择当前试衣标签页，再点击「开始体验」。页面只准备摄像头，连接或共享本身不会生成。

投屏复用当前智能镜的设备、素材、皮肤和体验状态，电脑继续处理摄像头、手势及生成，安卓全屏显示完整试衣区域。Chrome Region Capture 随页面尺寸裁切，不传后台、浏览器栏或其他标签页；误选窗口/其他标签页会停止该次共享并提示重选。需要 Chrome 的屏幕录制许可，首次使用可能还需 macOS 系统授权。此模式的操作在电脑完成，安卓不转发镜面触摸；安卓长按画面或返回键可打开设备设置。

共享页重复点击入口仅聚焦已有标签页，不重建试衣会话。停止共享、视频连接中断或安卓离线会停止本地与后台生成；停止未确认时须重试停止，恢复后重新共享并手动开始。旧 APK 未上报整页能力时显示升级提示，不发送错误嵌套画面。整页默认最高 1080p / 30 帧，分辨率可选 1080p 与 L1–L4，帧率可选 15/24/30；实际清晰度与帧率以网页尺寸、编码和网络为准。摄像头采集配置与传输输出配置独立。普通「安卓联动」、HDMI 和网页大屏保持原有入口。
